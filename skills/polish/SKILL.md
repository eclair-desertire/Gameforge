# Polish — «выглядит и ощущается готовой»

Unity-проект: сначала загрузи `unity:craft-game-floors` (если установлен) — он покрывает арт-стиль, свет, juice, звук, меню и оценку внешнего вида. Ниже — общий чеклист для всех движков.

## Чеклист

### Game feel (на каждое ключевое действие)
- [ ] Отклик < 100 мс, анимация антиципации/удара/восстановления
- [ ] Хит-стоп, тряска камеры (с ограничением и настройкой в опциях), частицы, вспышка
- [ ] Звук на каждое действие + вариации высоты тона
- [ ] Coyote time / input buffer для платформеров и экшна

### Аудио (подробно — gameforge:audio)
- [ ] Микшер с группами Music / SFX / UI / Ambience, громкость в настройках
- [ ] Нет клиппинга, музыка луп без щелчка
- [ ] Unity: `unity:audio-setup-mixers`, `unity:optimize-audio`

### UI/UX
- [ ] Онбординг: первая минута учит core loop без текста-простыни
- [ ] Масштабирование под разрешения/safe area (mobile — вырезы)
- [ ] Геймпад-навигация по меню (pc), крупные тач-зоны ≥ 44 pt (mobile)
- [ ] Локализация заложена (даже если пока один язык) — `unity:localization`

### Производительность (бюджеты из gdd.md, раздел 8)
- [ ] Профилирование на целевом железе, а не только в редакторе
- [ ] Draw calls / батчинг / атласы (`unity:manage-sprite-atlas`), LOD
- [ ] Нет GC-аллокаций в Update/_process/Tick в горячем пути
- [ ] Размер билда в бюджете (Unity Build Report; Godot — экспорт с исключениями; Unreal — pak/IoStore отчёт)
- [ ] Web-сборки: `unity:optimize-web`

## Процесс

1. Задачи полировки — в backlog milestone Polish через gameforge:plan.
2. Каждую — через gameforge:build, с проверкой скриншотом/записью до и после.
3. В конце — gameforge:playtest.
