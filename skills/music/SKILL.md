# Music — саундтрек кодом

## Перед началом: инструменты

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check-tools.py" --task music
```
Итог не «всё готово» → **сначала явно перечисли пользователю, что требуется установить** (FluidSynth, SoundFont, ffmpeg), и пройди gameforge:doctor (установка только с согласия). Без них работает только чиптюн в WAV — так и скажи, если пользователь отказался. В сессии должны быть инструменты `mcp__plugin_gameforge_gameforge-music__*`; `mus_status` показывает, какие рендеры доступны.

## Главное ограничение
Ты **не слышишь** звук. Качество проверяешь тем, что видно и измеримо:
- **piano roll** (`mus_compose` / `mus_edit` возвращают картинку): регистры не слипаются (бас < пэд < арпеджио < мелодия), мотив узнаётся и повторяется, фразы заканчиваются длинной нотой, плотность не «стена»;
- **анализ** (`mus_render` / `mus_analyze`): LUFS в цели, пик ≤ −1 dBFS, шов лупа «ok», баланс спектра (низ не съедает всё, есть верх);
- **финал — ушами пользователя**: дай ему файлы и спроси конкретно («мелодия запоминается? темп подходит сцене?»), правь по ответу.

## 1. Бриф (в `.gameforge/audio/music.md`)
Из GDD: сцена и её задача (исследование / бой / меню / победа), 3 прилагательных настроения, темп геймплея, длина сессии, платформа (громкость: −16 LUFS mobile, −18 pc), адаптивность (какие слои включаются от чего). Референсы — описанием жанра и инструментов, не чужими треками.

## 2. Пайплайн
1. `mus_theory mood=…` → лад, диапазон темпа, прогрессии, инструменты по ролям, стиль ударных. Настроения: heroic, adventure, calm, town, mystery, dungeon, battle, boss, sad, horror, chiptune, victory, game_over, lofi, electronic.
2. `mus_compose spec=…` — секции A/B (8+8 тактов) с разными прогрессиями, треки по ролям и **слоям** (1 база: пэд+бас · 2 ритм: ударные+арпеджио · 3 полный: мелодия). Посмотри piano roll; не нравится — другой `seed`, `contour`, `density`, прогрессия, или явные ноты (`role: notes`) для лейтмотива.
3. Лейтмотив игры — короткий мотив (2 такта) нотами; проводи его через темы (меню, город, бой) в разной оркестровке/ладу.
4. `mus_edit` — темп, транспонирование, инструмент, громкость/панорама, слой — без пересочинения.
5. `mus_render` — `loop` для внутриигровой музыки (бесшовно: рендер в два прохода, хвост реверберации переходит в начало), `stems: layers` для адаптивной музыки (стемы той же длины и с тем же усилением, что мастер — в движке складываются в мастер), `target_lufs`, `fmt: ogg` (Godot) / `wav` (Unity сожмёт сам) / `both`.
6. `mus_stinger` — победа, level up, предмет, находка, поражение, опасность, секрет; в тональности темы.
7. Строку `credits_line` из ответа `mus_render` (если рендер через SoundFont) — в `.gameforge/credits.md`.

## 3. Правила для игровой музыки
- **Лупы:** длина кратна тактам; первый такт не начинается с тишины; проверка шва — в ответе рендера.
- **Повторы утомляют:** 8 тактов на 100 BPM ≈ 20 с — для локации мало; 16–32 такта с секцией B, или горизонтальные вариации.
- **Не мешать геймплею:** мелодия не в частотах голоса и ключевых SFX (1–3 кГц) на громких местах; в бою ритм важнее мелодии.
- **Адаптивность:** вертикальные слои (стемы) по интенсивности; переходы на границе такта; стингеры поверх.
- **Чиптюн** (`instrument: square / pulse25 / pulse12 / triangle / saw / noise`) — 4 голоса, как на ретро-консолях; ударные — шумовые.
- **SoundFont** (General MIDI) — оркестр, гитары, синты; для «дорогого» звука финальный трек может переиграть композитор или пользователь в DAW по нашему MIDI.

## 4. FL Studio и другие DAW — вручную
Агент FL не управляет (MCP выключен по решению пользователя). Совместная работа:
- `mus_render` всегда кладёт `.mid` рядом — пользователь перетаскивает его в FL (по треку на канал) и переигрывает своими инструментами;
- его рендер из FL — `mus_analyze` (громкость, пики, шов лупа, спектр) и конкретные советы по миксу;
- `mus_load_midi` — загрузить его MIDI, посмотреть piano roll, отрендерить черновик или стемы.

## 5. Внедрение
Нормализация и форматы уже сделаны рендером; дальше — gameforge:audio (группы микшера, загрузка стримингом, синхронный старт стемов: Unity `AudioSource.PlayScheduled`, Godot `AudioStreamSynchronized` / `AudioStreamInteractive`, Unreal MetaSounds + Quartz). Проверка в игре: луп без щелчка, слои переключаются в такт, музыка не заглушает SFX.

## Права
Своя музыка — твоя; MuseScore_General SoundFont — MIT (копирайты — строкой в credits). Сторонние сэмплы и AI-сервисы — только с лицензией в credits. Не копируем мелодии существующих треков и игр.
