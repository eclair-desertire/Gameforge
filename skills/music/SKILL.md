# Music — саундтрек в FL Studio

## Перед началом: инструменты

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check-tools.py" --task music
```
Итог не «всё готово» → **сначала явно перечисли пользователю, что требуется установить или включить**, и пройди gameforge:doctor (установка только с его согласия). В сессии должны быть инструменты: `mcp__flstudio__*`; прописан, но инструментов нет — сервер не активен (doctor, шаг 5).

Инструмент: **`flstudio`** MCP (`mcp-templates/flstudio.json`; rosasynthesiz/flstudio-mcp — mixer, plugins, piano roll, step sequencer, patterns, playlist, анализ микса, MIDI-экспорт). Альтернативы: karl-andres/fl-studio-mcp; для Ableton — ahujasid/ableton-mcp. Без DAW — MIDI-файлы + gameforge:audio.

**Ограничения FL API (честно говорим пользователю):** загрузить плагин/сэмпл и отрендерить аудио агент не может — это делает пользователь (File → Export). Ноты в piano roll: один раз за сессию пользователь запускает скрипт `MCP_Apply` в piano roll. Остальное (ноты, паттерны, микшер, параметры плагинов, плейлист) — агент.

## 1. Музыкальный бриф (в `.gameforge/audio/music.md`)
Из GDD: жанр и темп геймплея, 3 прилагательных настроения, где звучит (меню / исследование / бой / босс / победа / поражение), длина сессии, платформа. Референсы — описанием жанра и инструментов, не чужими треками.

## 2. Композиция (агент предлагает, пользователь слушает)
- **Темп/лад**: исследование 70–100 BPM, бой 120–170; мажор/лидийский — светлое, минор/дорийский — приключение, фригийский/гармонический минор — угроза.
- **Лейтмотив** 4–8 тактов: проводи через все треки (меню, бой — в другой оркестровке).
- **Гармония**: 4-тактовые прогрессии (i–VI–III–VII, I–V–vi–IV и т. п.) + вариации, чтобы луп не надоедал за 2 минуты.
- **Партии по паттернам**: ударные / бас / пэд / аккорды / мелодия / контрмелодия / перкуссия — каждая отдельным паттерном и каналом микшера (это будущие стемы).
- Ноты пишутся в piano roll по сетке; гуманизация velocity ±10 и микросдвиги, кроме чиптюна.

## 3. Адаптивность (решается до аранжировки)
- **Вертикальные слои**: один луп, стемы включаются по интенсивности (тихо: пэд+бас → бой: +ударные+мелодия).
- **Горизонтальные секции**: A/B/интенсив с переходами по тактам.
- **Стингеры** 1–4 с: победа, смерть, находка, level up — в тональности основного трека.
- Луп-длина кратна тактам, хвост реверба заворачивается в начало (рендер с хвостом и склейка, или «tail» отдельным файлом).

## 4. Микс (через MCP: громкости, панорама, EQ/компрессия встроенных плагинов)
Ударные и бас по центру, бас mono < 120 Гц, мелодия на 1–3 кГц не должна спорить с SFX и голосом (вырежи там пэды), headroom −6 dB на мастере перед мастерингом. Используй анализ микса сервера и проверяй `verified` у параметров.

## 5. Рендер и внедрение
1. Пользователь рендерит: полный трек + **стемы** (по каналам микшера), WAV 48 kHz/24 bit.
2. Агент: нормализация и конвертация ffmpeg (см. gameforge:audio): музыка ≈ −16 LUFS (mobile) / −18…−23 LUFS (PC), пик ≤ −1 dBTP, OGG Vorbis q5–6 для движка.
3. Движок: Unity — AudioSource на каждый стем, синхронный старт через `PlayScheduled`, громкость слоёв по интенсивности, Mixer группа Music; Godot — `AudioStreamSynchronized` (слои) и `AudioStreamInteractive` (переходы), 4.3+; Unreal — MetaSounds + Quartz.
4. Проверка в игре: луп без щелчка, слои переключаются в такт, музыка не заглушает SFX.

## Права
Своя музыка, сэмплы из библиотек — с лицензией, записанной в `.gameforge/credits.md`; FL Studio и плагины — лицензии пользователя. Не копируем мелодии существующих треков и игр.
