# 2D art (HD) — GIMP MCP + gameforge-fx

## Перед началом: инструменты

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check-tools.py" --task art-2d
```
Итог не «всё готово» → **сначала явно перечисли пользователю, что требуется установить или включить**, и пройди gameforge:doctor (установка только с его согласия). В сессии должны быть инструменты: `mcp__gimp__*` и `mcp__plugin_gameforge_gameforge-fx__*`; прописан, но инструментов нет — сервер не активен (doctor, шаг 5).

Инструменты: **`gimp`** MCP (`mcp-templates/gimp.json`, GIMP 3.2+) и **`gameforge-fx`**. Для пиксель-арта — gameforge:pixel-art; для эффектов — gameforge:vfx.

## Принцип: собирать, а не «рисовать мышью»
Агент плохо рисует свободной рукой, но отлично **строит** изображение слоями: формы из выделений и путей → заливки градиентами → тени/света отдельными слоями в режимах Multiply/Overlay/Screen → текстура шумом/фильтрами → свечения и грейдинг. Так и работаем.

## Пайплайн
1. **Бриф** (из арт-библии `.gameforge/art/style.md`): размер, назначение, свет, палитра (`fx_palette`), референсы описанием.
2. **Холст и слои** с понятными именами: `bg`, `shape_*`, `shade_*`, `light_*`, `fx_*`, `text`.
3. **Формы**: выделения (эллипсы, пути), заливка базовым цветом рампы.
4. **Объём**: градиенты по направлению света; ambient occlusion — тёмный мягкий слой Multiply в стыках; rim light — тонкий светлый край со стороны контрового света.
5. **Материал**: шум/текстурные фильтры с маской (камень, металл, ткань), контролируемая сила.
6. **Финиш**: `fx_post` — glow, shadow, grade (единая цветовая температура по всем ассетам), outline при необходимости; для 2D-света — `fx_normal_map`.
7. **Проверка**: `get_state_snapshot` GIMP или `fx_view` — смотри целиком и в зуме на лица/детали; сравни рядом с соседними ассетами игры.

## Типовые задачи
| Задача | Как |
|--------|-----|
| Бесшовная текстура | Filters → Map → Tile Seamless, проверка мозаикой 2×2; 512/1024/2048, степень двойки |
| PBR-заготовки | albedo без света → height из яркости → normal (`fx_normal_map`, или Filters → Generic → Normal Map) → roughness инвертированным контрастом |
| UI / иконки | 9-slice с одинаковыми полями, иконки на сетке 64/128, единый стиль обводки и тени; экспорт @1x/@2x |
| Steam-капсулы | header 920×430, small 462×174, main 1232×706, vertical 748×896, library 600×900 и hero 3840×1240, logo PNG с прозрачностью. Логотип читается на маленькой капсуле; без рейтингов и цитат на капсуле (правила Steam) |
| Скриншоты стора | реальные кадры игры + грейдинг; никаких «фейковых» сцен |
| Иконка приложения | 1024×1024, без прозрачности (iOS), крупная форма, тест на 48 px |

## AI-генерация изображений
Только если пользователь сам выбрал сервис и добавил ключ. Запиши сервис, дату и условия коммерческого использования в `.gameforge/credits.md`. Результат всё равно проходит доводку: палитра, свет, стиль.

## Правила
- Не воспроизводим чужой арт, персонажей, логотипы и стиль конкретной игры один в один.
- Исходники `.xcf` — в `art/2d/`, экспорт PNG — в ассеты движка; маркетинговые — в `marketing/`.
