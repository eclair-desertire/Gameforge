# Design — живой GDD

GDD — **рабочий инструмент, а не роман**. Одна страница на раздел максимум. Документ синхронизирован с кодом: если поведение игры расходится с GDD — правим одно из двух.

## Шаги

1. Прочитай `concept.md`. Без вердикта «делаем» — предупреди (см. ворота в gameforge:studio).
2. **3 столпа.** Короткие, проверяемые («каждое действие ощущается мощно», «сессия ≤ 3 минут»). Любая будущая фича проверяется вопросом «служит ли столпу?».
3. **Core loop** — шаги на 5 с / 30 с / 5 мин. Для каждой механики в таблицу: ввод → правило → обратная связь (звук, частицы, камера, хит-стоп) → статус.
4. **Прогрессия и экономика.** Ресурсы, источники и стоки. Цифры баланса **сразу как данные**, а не в коде: Unity — ScriptableObject, Godot — Resource (.tres), Unreal — DataTable/DataAsset. Сам GDD хранит формулы и смысл, таблицы — в движке.
5. **Тех-рамки** по треку:
   - mobile: 60 FPS на среднем Android, билд ≤ 150 МБ (лучше ≤ 100), сессия 2–5 мин, портрет/ландшафт, офлайн.
   - pc: целевое железо (Steam Deck как минимум — хорошая планка), геймпад, разрешения, сохранения в облако Steam.
6. **Scope:** MVP (то, что попадёт в прототип и вертикальный срез), полная версия, **cut list** — упорядоченный список того, что режем первым.
7. Значимые технические решения (архитектура, сеть, сохранения, выбор пакета) — ADR в `.gameforge/decisions/` по `templates/adr.md` или через `claude-code-game-studios:architecture-decision`.

Тяжёлую проработку (баланс, экономика, нарратив) отдай агенту `game-designer`.

## Сохранение GDD

- GDD всегда лежит в `.gameforge/gdd.md` — единственный источник дизайна; не дублируй его в других местах (в context.md — только столпы и core loop одной строкой).
- Каждое изменение: поднять `Версия` и `Обновлён` в шапке + строка в «Истории изменений» (версия, дата, раздел, что, почему).
- Снимок `.gameforge/archive/gdd-v<версия>-<YYYY-MM-DD>.md` — при завершении этапа design, каждом закрытии milestone и перед крупной переделкой.
- Пользователь хочет документ «для людей» (PDF/Word/Google Docs) — экспортируй копию из gdd.md, но источником правды остаётся gdd.md.

## Выход

- `gdd.md` заполнен минимум до разделов 1, 2, 3, 8, 9, версия 0.1+, снимок в archive/.
- `context.md`: столпы, core loop, глоссарий обновлены; запись в `history.md`.
- `state.md`: ворота design, `stage: prototype`, «Следующий шаг: gameforge:plan (milestone Prototype)».
