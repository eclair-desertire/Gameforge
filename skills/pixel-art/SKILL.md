# Pixel art — не «квадратики», а читаемый стиль

## Перед началом: инструменты

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check-tools.py" --task pixel-art
```
Итог не «всё готово» → **сначала явно перечисли пользователю, что требуется установить или включить**, и пройди gameforge:doctor (установка только с его согласия). В сессии должны быть инструменты: `mcp__aseprite__*` и `mcp__plugin_gameforge_gameforge-fx__*`; прописан, но инструментов нет — сервер не активен (doctor, шаг 5).

Инструменты: **`aseprite`** MCP (шаблон `mcp-templates/aseprite.json`) — рисование, слои, анимация, экспорт; **`gameforge-fx`** (встроен в плагин) — палитры, просмотр с lint, пост-обработка, VFX. Нет Aseprite → рисуй Lua-скриптом в batch-режиме Aseprite или собирай PNG через `fx_post`/Python, но правила те же.

## 0. Перед первым пикселем
1. **Арт-библия проекта** — `.gameforge/art/style.md` (создай, если нет): разрешение спрайтов, размер тайла (16/24/32), направление света (по умолчанию сверху-слева), палитра (файл `.gpl`), outline-стиль, референсы *описанием* (не копируем чужие игры и персонажей).
2. **Палитра первой**: `fx_palette action=ramp bases=[...]` — 4–8 рамп по 4–6 оттенков, тени холоднее (к синему/фиолетовому), света теплее (к жёлтому). 16–32 цвета на всю игру. Сохрани `art/palette.gpl` и грузи её в Aseprite. Готовые палитры (Lospec) — только с проверкой лицензии.
3. Размер под камеру: персонаж 16–32 px (mobile/ретро), 48–64 px (детальный PC). Тайл = сетка уровня из gameforge:level-design.

## 1. Пайплайн спрайта
1. **Силуэт** одним тёмным цветом — читается ли поза и роль на 1x? Если нет — правь силуэт, не детали.
2. **Плоские цвета** (средний тон каждой рампы), чёткие зоны материалов.
3. **Свет и тень**: 2–3 тона на форму по направлению света; тень формы + падающая тень. Никакого pillow shading (тёмный контур по краю, светлый центр).
4. **Кластеры**: пиксели одного цвета группами, без одиночного «шума» (orphan pixels — `fx_view` их считает).
5. **Линии**: ровные шаги (1-2-3, не 1-3-1), без «двойных» пикселей на диагоналях; ручной AA промежуточным цветом только на крупных кривых.
6. **Selective outline (sel-out)**: контур темнее локального цвета, а не сплошной чёрный; снаружи силуэта — тёмный, со стороны света — светлее или разрыв.
7. **Детали в последнюю очередь** и только читаемые на 1x. Дизеринг — экономно, для градиентов неба/металла, не на персонаже.

## 2. Анимация
- База: 8–12 fps, ключи → промежуточные. Idle 4–6 кадров, бег 6–8, атака: **anticipation (2) → удар/smear (1–2) → hold (2–3) → recovery**.
- Squash & stretch, вторичное движение (волосы, плащ) с задержкой на 1–2 кадра; sub-pixel анимация сменой оттенков.
- Импакт-кадр держи дольше; эффекты (вспышка, искры) — gameforge:vfx в той же палитре.
- Onion skin / сравнение кадров инструментами Aseprite MCP; проверяй `fx_sheet action=gif`.

## 3. Тайлсеты
47-тайловый blob / 16-тайловый autotile для стен и земли; бесшовность проверяй, собрав 3×3 участок; вариации (2–4) против повторяемости; в Unity — `unity:create-tile-palette-or-rule-tiles`, в Godot — TileSet terrains.

## 4. Контроль качества (обязательно, после каждого шага)
1. Экспорт → `fx_view` (zoom) — смотри на 1x и 4x, на тёмном и светлом фоне.
2. Чек-лист: силуэт читается · цветов ≤ палитры · нет полупрозрачных пикселей (если стиль hard-alpha) · нет orphan-шума · свет с одной стороны · контраст персонажа к фону уровня · стиль совпадает с соседними спрайтами.
3. Не проходит — исправь и покажи снова. Пользователю показывай превью до того, как класть в проект.

## 5. Экспорт в движок
| Движок | Настройки |
|--------|-----------|
| Unity | Texture Type Sprite, Filter **Point**, Compression **None**, PPU = размер тайла, Sprite Mode Multiple + Grid; камера `unity:2d-pixel-perfect`; атласы `unity:manage-sprite-atlas`; нарезка `unity:sprite-editor` |
| Godot | Import: Filter Off (или Project Settings → Default Texture Filter = Nearest), `AnimatedSprite2D` + SpriteFrames, snap 2D transforms/vertices to pixel |
| Unreal | Paper2D, Texture Group 2D Pixels, Filter Nearest |

Нормали для 2D-света — `fx_normal_map`. Исходники `.aseprite` — в `art/pixel/`, экспорт — в папку ассетов движка.
