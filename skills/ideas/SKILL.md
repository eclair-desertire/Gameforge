# Ideas — брейншторм с учётом трендов

Результат — `.gameforge/ideas/<YYYY-MM-DD>.md` (шаблон `templates/ideas.md`): сигналы с датами и ссылками → идеи → оценка → топ-3.

## 0. Рамки (спроси, если не сказано)

Трек (mobile / pc / both), сколько месяцев готов вложить, любимые жанры, чего точно не хочет делать, движок. Если в `.gameforge/` уже есть прошлые сессии идей — прочитай их, не повторяйся.

## 1. Сбор сигналов (WebSearch / WebFetch, всё с датой)

Сбор сигналов — механическая работа: отдай её агенту `scout` (haiku) — по одному на источник параллельно (Steam, мобильные чарты, соцсети/Reddit, джемы), с просьбой вернуть 5–10 сигналов с датой и ссылкой. Кластеризацию и идеи делай сам.

Тренд без даты — не тренд. Бери данные за последние 1–3 месяца, у каждого сигнала указывай источник и дату.

| Трек | Где смотреть | Что вытаскивать |
|------|--------------|-----------------|
| pc | Steam: New & Trending, Top Sellers, Popular Upcoming (по вишлистам), итоги последнего Next Fest, SteamDB charts / followers | жанры и теги, которые растут; механики, повторяющиеся у 3+ игр; цена; на что жалуются в отзывах |
| pc | itch.io (popular / new & popular), темы и победители последних геймджемов (Ludum Dare, GMTK, Brackeys) | свежие механики-прототипы, которые ещё не взял рынок |
| mobile | топ-чарты App Store / Google Play (бесплатные, новые), блоги аналитиков (AppMagic, Sensor Tower, GameRefinery, Liftoff), рекламные креативы (Meta Ad Library) | что качают, какие креативы крутят дольше всего (значит, окупаются) |
| оба | TikTok / YouTube Shorts / Reels, Reddit (r/gaming, r/IndieDev, r/gamedev, жанровые сабы), Twitch-категории | мемы, эстетика, «залипательные» механики, которые хорошо смотрятся в 10-секундном видео |

Ускорители, если установлены: `game-trend-skills:scanning-game-trends` (рынок mobile), `game-trend-skills:scouting-social-trends` (соцсети) — запускай их и используй выводы как сигналы.

## 2. Кластеризация

Сгруппируй сигналы в 4–8 трендов: «название — 2–3 доказательства — стадия (растёт / пик / выдыхается) — насыщенность (мало / средне / много клонов)». Тренд на пике с кучей клонов — плохая ставка для соло-разработчика, если нет сильного твиста.

## 3. Генерация идей (10–15 штук)

Формула: **тренд × проверенная механика × твист × скоуп**. Приёмы:
- сеттинг или эстетика из тренда + жанр с понятным core loop;
- механика из jam-победителя + доступная платформа (mobile/Steam Deck);
- «жалоба в отзывах» популярной игры → игра, которая её решает;
- скрещивание двух жанров, у каждого из которых есть своя аудитория.

У каждой идеи: хук в одну фразу, core loop в одну строку, на какие тренды опирается, что вызывает «вау» в первые 10 секунд видео. Жанр и механики — можно, клон конкретной игры (имя, персонажи, арт, уровни) — нет.

## 4. Оценка (1–5, вес)

| Критерий | Вес | Вопрос |
|----------|-----|--------|
| Хук | ×3 | понятно и цепляет за 3 секунды видео? |
| Рынок | ×2 | тренд растёт, аудитория есть, ниша не забита? |
| Скоуп | ×2 | MVP в срок пользователя (mobile ≤ 3 мес, pc ≤ 12)? |
| Фит | ×2 | сочетается с навыками, движком и желаниями пользователя? |
| Маркетируемость | ×1 | легко сделать гифку, трейлер, креатив? |
| Риск | ×1 | (5 = низкий) техника, контент, монетизация |

Для mobile дополнительно прогони топ-5 через `game-trend-skills:evaluating-game-ideas`, если он есть.

## 5. Выход

- Топ-3 с аргументами и **самым дешёвым тестом** для каждой (см. gameforge:concept, шаг 6).
- Пользователь выбирает → gameforge:concept с выбранной идеей. `state.md` → «Следующий шаг: gameforge:concept <идея>».
- Отсеянные идеи не выбрасывай — они остаются в файле сессии как банк.
