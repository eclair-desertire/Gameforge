# Audio — звук и музыка

## Перед началом: инструменты

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/check-tools.py" --task audio
```
Итог не «всё готово» → **сначала явно перечисли пользователю, что требуется установить или включить**, и пройди gameforge:doctor (установка только с его согласия). В сессии должны быть инструменты: — (MCP не нужен; ffmpeg для обработки); прописан, но инструментов нет — сервер не активен (doctor, шаг 5).

Рабочие файлы: `.gameforge/audio/sound-list.md` (шаблон `templates/sound-list.md`) и `.gameforge/credits.md` — **каждый сторонний звук с лицензией и источником**.

## 1. Направление

В gdd.md раздел 7: настроение (3 прилагательных), референсы по жанру (описанием, не чужими треками), палитра инструментов, стиль SFX (реалистичный / мультяшный / 8-бит / синтетический), что звучит громче всего (обратная связь игроку важнее фона).

## 2. Список звуков из механик

Пройди таблицу механик gdd.md: **у каждого действия игрока и каждого события есть звук**. Для частых звуков — 3–5 вариаций + рандом pitch ±5–10%, иначе «пулемётный» эффект. Группы: Player, Enemies, UI, World/Ambience, Music, Voice. Приоритет: core loop → UI → враги → эмбиент.

## 3. Откуда брать звук

| Путь | Когда | Лицензия |
|------|-------|----------|
| Своя генерация в коде: sfxr/jsfxr, ChipTone, Bfxr | ретро, UI, прототип | своё |
| Синтез/Foley самому (Audacity, Reaper, Vital) | уникальный характер | своё |
| Библиотеки: Sonniss GDC bundle, Kenney audio, freesound.org (только CC0/CC-BY), OpenGameArt | быстрые качественные SFX | читать лицензию каждого файла; CC-BY → строка в credits |
| AI-генерация SFX/музыки (сервисы text-to-audio) | черновики, эмбиент | **проверить коммерческие права в тарифе пользователя**; записать сервис и дату в credits |
| Композитор / стоковая музыка | финальная музыка pc-проекта | договор/лицензия на игру и трейлеры |

Ключи API, оплату и регистрацию в сервисах делает пользователь. Не используй звуки и музыку из других игр, фильмов и треков исполнителей.

## 4. Музыка

Сочинение и аранжировка в FL Studio через MCP — скилл **gameforge:music**. Здесь — общие требования к музыке в игре.


- Лупы без щелчка (переход по нулю, хвост реверба в начало), длина кратна тактам.
- Адаптивность: вертикальные слои (бой добавляет ударные), горизонтальные переходы по тактам, стингеры на события (победа, смерть, находка).
- Меню, геймплей, бой, победа/поражение — минимальный набор треков.

## 5. Обработка (агент может сам через ffmpeg)

```bash
ffmpeg -i in.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 out.wav   # нормализация громкости
ffmpeg -i in.wav -af "silenceremove=start_periods=1:start_threshold=-50dB" out.wav  # срезать тишину в начале
ffmpeg -i in.wav -c:a libvorbis -q:a 5 out.ogg                         # сжатие для музыки
```

Ориентиры громкости: общий микс около -16 LUFS (mobile) / -18…-23 LUFS (pc/консоли), пики ≤ -1 dBTP. SFX короче 1 с — WAV/ADPCM, музыка — Vorbis/AAC стримингом.

## 6. Внедрение

| Движок | Как |
|--------|-----|
| Unity | Audio Mixer: группы Master → Music / SFX / UI / Ambience, exposed-параметры громкости в настройки; `unity:audio-setup-mixers`, `unity:optimize-audio` (Load Type, сжатие, mono для 3D) |
| Godot | Audio Bus Layout (`default_bus_layout.tres`), `AudioStreamPlayer` / `2D` / `3D`, `AudioStreamRandomizer` для вариаций, `AudioStreamInteractive` для адаптивной музыки (4.3+) |
| Unreal | MetaSounds, Sound Classes + Sound Mix, Submix, Attenuation; Quartz для синхронизации с тактами |
| Middleware | FMOD / Wwise — для больших pc-проектов с адаптивной музыкой; бесплатны для малых бюджетов по их условиям |

Обвязка в коде: один AudioService/шина событий («PlayerJumped» → звук), а не `PlaySound` разбросанный по геймплейному коду.

## 7. Проверка

Запусти игру, пройди core loop: каждое действие слышно, ничего не клиппит, громкость по группам регулируется, звук корректно глушится при паузе/сворачивании (mobile), 3D-звуки затухают с расстоянием. Обнови sound-list (статус) и credits.
