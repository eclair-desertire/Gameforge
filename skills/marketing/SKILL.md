# Marketing — с первого прототипа, а не после релиза

План и календарь — `.gameforge/marketing.md` (шаблон `templates/marketing-plan.md`).

**Ничего не публикуй, не отправляй и не рассылай сам.** Ты готовишь тексты, ассеты, списки и расписание; посты, письма, загрузку страницы и рекламу запускает пользователь (или ты — после его явного «да» на конкретное действие). Подбор людей для рассылки — только из публичных бизнес-контактов (страницы для прессы, формы на сайтах), без сбора личных данных.

## 1. Позиционирование (на этапе concept)

- Хук в одну фразу и **«ощущение» в одном слове** — проверь, что их можно показать в 3-секундном видео без текста.
- Аудитория: «игроки в X и Y, которым не хватает Z». Отсюда — теги Steam, категории сторов, сабреддиты, стримеры.
- 3 ключевых тезиса для всех текстов.

## 2. Ассеты (растут с игрой)

| Ассет | Когда | Требования |
|-------|-------|------------|
| Гифки / 10–15 с клипы core loop | с прототипа | без UI-мусора, действие с первого кадра, 1 мысль на клип |
| Капсулы Steam (main, small, header, library, vertical) | vertical slice | читаемый логотип на маленьком размере, персонаж/действие, без мелкого текста; размеры — по текущим требованиям Steamworks |
| 5–10 скриншотов | vertical slice | разные механики и локации, 16:9, реальная игра |
| Трейлер 30–60 с | vertical slice → обновлять | первые 5 с — геймплей, а не логотип; ритм под музыку; конец — CTA «Wishlist now» / «Download» |
| Пресс-кит (presskit()-формат) | до анонса | факты, описание, скрины, лого, трейлер, контакты |
| Мобильные креативы | до тест-публикации | 15–30 с, хук в первые 2 с, вертикаль 9:16, 3–5 вариантов для A/B |

Запись видео: в движке через Unity Recorder / Godot Movie Maker (`--write-movie`) / Unreal Movie Render Queue; монтаж — ffmpeg (склейка, обрезка, масштаб) или редактор пользователя. Скриншоты для капсул — с отдельной камерой и пост-эффектами.

## 3. Каналы

### pc
- **Steam-страница как можно раньше** (с vertical slice): «Coming soon», вишлисты копятся месяцами. Ориентир для решения о релизе — количество вишлистов к старту и их прирост.
- **Steam Next Fest** — с демо; подавать заранее по календарю Steamworks. Демо короткое и заканчивается на пике.
- Тематические фестивали Steam и стороних организаторов, сборники (bundles) после релиза.
- Стримеры и YouTube: список каналов по жанру и размеру (малые и средние отвечают чаще), ключи через сервисы раздачи ключей, письмо — коротко, гифка, ключ, без вложений.
- Пресса: только если есть повод (анонс, дата, демо, награда).

### mobile
- ASO: название + подзаголовок с ключевыми словами, иконка (тест 2–3 вариантов), первые 2 скриншота решают.
- Креативы → CPI-тест до продакшна (см. gameforge:concept, gameforge:live). Платный UA — только когда метрики выше порога.
- Детали бесплатного запуска — `game-trend-skills:launching-on-zero-budget`.

### оба
- Devlog / короткие видео (TikTok, Shorts, Reels, Twitter/X, Bluesky): 2–3 поста в неделю, формат «до/после», «баг смешной», «как я сделал X», «угадай механику». Свежие форматы — `game-trend-skills:scouting-social-trends`.
- Reddit: r/IndieDev, r/indiegames, жанровые сабы — по их правилам саморекламы (обычно дни/треды для этого).
- Discord-сервер — когда есть хотя бы 50–100 заинтересованных; ранний доступ к билдам и плейтестам (gameforge:playtest).

## 4. Календарь по этапам

| Этап игры | Маркетинг |
|-----------|-----------|
| concept | хук, аудитория, тест-креатив/гифка |
| prototype | devlog-посты, гифки, сбор первых откликов |
| production / vertical slice | Steam-страница, трейлер v1, пресс-кит, Discord |
| polish | демо, Next Fest, стримеры, трейлер v2 с датой |
| release | анонс даты за 4–6 недель, рассылка ключей, пост-релизные посты, скидка запуска |
| live | апдейты = поводы для постов, распродажи, бандлы |

## 5. Метрики

Сохраняй в `marketing.md`: вишлисты/день, CTR и конверсия страницы (Steamworks UTM-ссылки по каналам), просмотры и переходы по постам, CPI/CTR креативов. Канал без результата за 4–6 недель — урезать, работающий — усилить.
