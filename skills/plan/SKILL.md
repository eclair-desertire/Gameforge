# Plan — milestone и задачи

## Принципы

- **Задача = одна сессия Claude.** Больше — дроби. Каждая задача имеет «Готово, когда:» (наблюдаемое поведение) и «проверка:» (тест / playmode-скрин / headless-прогон / ручной плейтест).
- **Сначала то, что проверяет риск.** В прототипе — core loop и самое сомнительное из рисков concept.md. Меню, сохранения, настройки — после.
- **Greybox first.** Арт — кубы и капсулы, пока core loop не доказан.

## Milestones по этапам

| Milestone | Что входит | Чего НЕ делаем |
|-----------|-----------|----------------|
| Prototype | core loop, 1 уровень/арена, примитивный UI, debug-кнопки, инструменты тюнинга | меню, сохранения, арт, звук (кроме 2–3 заглушек для feel) |
| Vertical slice | 5–15 минут игры в финальном качестве: арт-стиль, звук, juice, онбординг | масштаб контента |
| Content | уровни/враги/предметы по GDD, экономика, прогрессия | новые механики не из GDD |
| Polish | см. gameforge:polish | новые фичи |
| Release | см. gameforge:release | всё, кроме багфиксов |

Для pc-трека в Vertical slice добавь задачу «Steam-страница: капсулы, скриншоты, трейлер-тизер» — вишлисты копятся месяцами.

**Каждый milestone планируется по всем потокам**, а не только по коду. Префиксы задач: `[code]`, `[qa]`, `[level]`, `[art]`, `[audio]`, `[mkt]`, `[build]`. Минимум на milestone:

| Milestone | level | art | audio | mkt |
|-----------|-------|-----|-------|-----|
| Prototype | метрики + greybox 1 уровня | только greybox-цвета | 2–3 заглушки на core loop | хук, 2–3 гифки, devlog-пост |
| Vertical slice | 1 уровень в финальном качестве | модульный кит/герой в Blender, арт-стиль | SFX core loop, 1 трек | Steam-страница / креативы, трейлер v1, пресс-кит |
| Content | все уровни по прогрессии | киты и персонажи под контент | полный sound list | регулярный контент, Discord |
| Polish | правки по плейтестам | LOD, оптимизация | микс, громкость | демо, Next Fest, стримеры |

## Шаги

1. Прочитай `state.md`, `gdd.md` (scope), текущий `backlog.md`.
2. Распиши задачи текущего milestone в формате из шапки backlog.md. ID — `P-01`, `VS-01`, `C-01`, `PL-01`, `R-01`.
3. Упорядочь: риск → зависимости → ценность.
4. Если задача касается подсистемы, для которой есть узкий скилл (UI, физика 2D, навигация, локализация, IAP, мультиплеер), отметь его в задаче: `скилл: unity:ui`.
5. Для делегирования агентам-кодерам вне Claude Code — `game-trend-skills:writing-game-agent-briefs`.
6. Покажи пользователю первые 3–5 задач и предложи начать с первой через gameforge:build.

## Выход

`backlog.md` обновлён; в `state.md` — «Следующий шаг: gameforge:build <ID>».
