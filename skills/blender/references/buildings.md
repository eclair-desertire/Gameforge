# Реалистичные здания и окружение

## 1. Референс и паспорт здания

Перед моделированием запиши в задачу: стиль и эпоха (сталинка, хрущёвка, викторианский таунхаус, современный офис, японский дом…), этажность, материалы фасада, 3–5 характерных деталей стиля, состояние (новое / жилое / заброшенное). Если пользователь дал фото — опиши пропорции по ним.

## 2. Реальные размеры (метры)

| Элемент | Типично |
|---------|---------|
| Высота этажа (жилой / коммерческий) | 2.8–3.2 / 3.5–4.5 |
| Толщина наружной стены | 0.25–0.5 (кирпич 0.38–0.64) |
| Окно жилое | 1.2–1.5 × 1.4–1.8, подоконник на 0.8–0.9 от пола |
| Дверь входная | 0.9–1.2 × 2.1–2.4 |
| Ступень | высота 0.15–0.18, глубина 0.28–0.32 |
| Перила / парапет | 0.9–1.1 |
| Цоколь | 0.5–1.2 |

Сетка модульного кита — 0.5 или 1 м по горизонтали, высота этажа по вертикали. Пивоты модулей — в углу на сетке, чтобы снап в движке работал.

## 3. Модульный кит (для игр это стандарт)

Делай не «одно здание», а **кит**, из которого собираются сотни зданий:

- стена глухая / с окном / с дверью / угловая внешняя / угловая внутренняя
- цоколь, межэтажный пояс, карниз, парапет, угол-пилястра
- окна: рама, откос, подоконник, перемычка, наличник — отдельные объекты с вариантами (открыто, шторы, тёмное, разбито)
- балкон, козырёк, водосточная труба, кондиционер, вывеска, решётки, провода
- крыша: скат, конёк, слуховое окно, труба

Каждый модуль — отдельный объект в коллекции `KIT_<style>`, имя `SM_<Style>_<Element>_<Variant>`.

## 4. Порядок моделирования через `execute_blender_code`

1. **Блокаут** — кубы по размерам здания и этажей. `look` сверху и в 3/4.
2. **Стены** — плоскости с Solidify, вырезы проёмов через Boolean (затем применить и почистить) или моделирование вокруг проёма для чистой топологии.
3. **Проёмы** — откосы на всю толщину стены (без них фасад плоский — главный признак «нереалистичности»).
4. **Окна и двери** — рама с профилем, стекло отдельным объектом/материалом.
5. **Архитектурные профили** (карниз, пояса, наличники) — кривая-профиль + `Curve → Bevel object` или Screw/Array по пути → в меш.
6. **Расстановка** по фасаду — Array/Geometry Nodes (instance on points по сетке) с рандомизацией вариантов окон.
7. **Фаски** — модификатор Bevel (0.005–0.02 м, 2–3 сегмента, `limit_method='ANGLE'`) + Weighted Normal. Острые углы без фасок = CG-вид.
8. **Мелочи и «жизнь»** — трубы, кабели, кондиционеры, таблички, цветы, мусор — это 50% реализма.

После каждого шага — `look` (solid), после материалов — `look` (material и rendered с HDRI Poly Haven).

## 5. Материалы

- Базовые PBR — Poly Haven (`search_assets` → кирпич, штукатурка, бетон, металл, дерево; CC0).
- **Trim sheet** для профилей и мелких деталей — одна текстура на кучу модулей → меньше draw calls.
- **Вариативность**: вертекс-цвет или маски для грязи снизу, потёков под окнами, выгорания; разные оттенки штукатурки на модулях.
- **Износ**: edge wear по кривизне/AO (bake в маску), декали (трещины, граффити, пятна) отдельными плоскостями.
- Стекло: отражение + тёмная «комната» (в движке — interior mapping шейдер вместо реальных интерьеров).

## 6. Игровая подготовка

- UV: модули — Cube/Box projection или Smart UV с единым texel density; trim-элементы — уложены на полосы trim sheet.
- LOD: LOD1 — убрать мелкие детали и фаски (Decimate / вручную), LOD2 — упрощённая коробка с запечённой текстурой фасада.
- Коллизии: простые боксы, не меш здания. Нейминг — см. export.md.
- Большие города: в движке через PCG (Unreal), Splines/скрипты (Unity), MultiMesh / GridMap (Godot) из кита, а не тысячи уникальных мешей.

## 7. Пропсы и сложная органика

Деревья, скульптуры, сложные пропсы — `search_assets` (Poly Haven) или `generate_3d` (Rodin / Hunyuan3D / Tripo / Meshy), затем обязательно: проверить масштаб, Decimate/ретопология под бюджет, пересобрать UV при необходимости, свой материал в стиле игры, запись в credits.md.
