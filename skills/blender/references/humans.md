# Реалистичные люди и персонажи

Реалистичного человека **не моделируют с нуля Python-скриптом** — анатомия, топология для анимации и кожа требуют специализированных инструментов. Пути по качеству:

| Путь | Качество | Риг/анимация | Когда |
|------|----------|--------------|-------|
| **MPFB2** (MakeHuman for Blender) | реалистичная анатомия, лица, кожа | встроенные риги, shape keys | герои, NPC, толпы — **основной путь** |
| `generate_3d` (Rodin, Hunyuan3D, Tripo, Meshy) из текста/картинки | хорошая форма, слабая топология | нужен авто-риг (Mixamo/Rigify) | второстепенные NPC, статуи, стилизация |
| Скульпт + ретопология вручную | максимум | ручной риг | только если пользователь сам художник |

## MPFB2

- Бесплатный open-source генератор людей для Blender, распространяется как extension (Blender 4.2+). Установка — через Get Extensions в Blender или с сайта MakeHuman Community; делает пользователь.
- **Лицензия:** core-ассеты (базовый меш, таргеты, скины) — **CC0**, модели можно использовать и продавать в закрытых коммерческих играх. **Сторонние ассеты из паков (одежда, волосы, скины) могут иметь другие лицензии** — проверяй каждый и пиши в credits.md. Код MPFB — GPL (это не касается созданных моделей).
- MCP-интерфейса у MPFB нет, но он скриптуется из Python → управляем через `execute_blender_code`. Сначала **исследуй API в живом Blender** (найди модуль расширения в `bpy.context.preferences.addons.keys()` и его сервисы через `dir()`), а не угадывай имена функций. Есть ранний бета-мост makehumancommunity/mpfb-mcp — опционально.

### Рабочий рецепт MPFB 2.0 через `execute_blender_code` (проверено на Blender 5.3)

```python
BASE = "bl_ext.user_default.mpfb"                       # имя модуля расширения
HS = importlib.import_module(BASE + ".services.humanservice").HumanService
LS = importlib.import_module(BASE + ".services.locationservice").LocationService
DATA = LS.get_user_data()                               # тут лежат skins/, eyes/, hair/, clothes/…
body = HS.create_human(macro_detail_dict=macro, feet_on_ground=True, scale=0.1)
rig = HS.add_builtin_rig(body, "game_engine")           # 1) РИГ ДО ОДЕЖДЫ — иначе одежда не следует за позой
HS.set_character_skin(<skins/…/*.mhmat>, body, skin_type="ENHANCED_SSS")
HS.add_mhclo_asset(<eyes|eyebrows|eyelashes|teeth|tongue|hair|clothes/*.mhclo>, body, asset_type="Eyes"|…|"Clothes", subdiv_levels=1, material_type="MAKESKIN")
```
- `macro`: `gender` 0..1, `age` (0.5 = 25 лет, 1.0 = 90; лет → `0.5 + (лет-25)/65*0.5`), `muscle`, `weight`, `proportions`, `height`, `cupsize`, `firmness`, `race` {asian, caucasian, african}. Рост нелинеен по `height` и зависит от race — **измеряй** по вершинам вычисленного меша и подгоняй (мужчина 1.75–1.85, женщина 1.60–1.70).
- Поза: в MPFB только T-pose. Вращай кости **в пространстве скелета**: `q = (M⁻¹ · R_armature · M)`, `M = bone.matrix_local`. Угол руки считай по `tail_local - head_local` (**`Bone.vector` — в пространстве родителя!**). Руки вниз ≈ 85–87° от горизонтали, локоть −8° вперёд, предплечье с поворотом ладонями к бёдрам, фаланги согнуть 10–30° — иначе «манекен».
- Одежда ассет-пака: часть футболок с логотипом MakeHuman — для игры бери без логотипа или замени текстуру.
- После каждого шага — рендер крупного плана (лицо, руки, ткань) с DOF, а не только общий план.
- Готовая функция `person(...)` — `../examples/street/70_human.py`.

### Порядок

1. **Паспорт персонажа**: роль, возраст, пол, телосложение, рост, происхождение, одежда, состояние (ухоженный/уставший/раненый), 3 отличительные черты. Без копирования реальных людей и чужих персонажей.
2. **Базовое тело**: макро-параметры (пол, возраст, мышцы, вес, рост, пропорции, этнический микс) → затем микро-таргеты лица (нос, скулы, челюсть, глаза, губы). Асимметрия чуть-чуть — идеальная симметрия выглядит неживой.
3. **Proxy-топология** под бюджет (в MPFB есть упрощённые proxy-меши) — для игр обычно не базовый high-poly.
4. **Кожа**: реалистичный skin-материал MPFB (с SSS), отдельные материалы глаз (влажность, роговица), брови/ресницы, зубы/язык.
5. **Волосы**: для игр — **hair cards** (полосы с альфа-текстурой), не particle/curves hair. Частицы допустимы для рендера, но в движок их надо конвертировать в карты.
6. **Одежда**: из ассетов MPFB (fitting под тело) или своя; проверить пробой тела одеждой в позах (удалить скрытые полигоны тела под одеждой — экономия и нет пробоя).
7. **Риг**: «game engine» / Mixamo-совместимый риг MPFB для игр или Rigify для сложной анимации. Проверь веса в крайних позах (присед, руки вверх, поворот головы) — `look` в каждой.
8. **Лицо**: shape keys для эмоций и визем (lip sync), если персонаж говорит в кадре.
9. **Анимации**: Mixamo (аккаунт Adobe — у пользователя), своя анимация, motion capture-библиотеки (лицензии!), ретаргет в движке (Unity Humanoid / Unreal IK Retargeter / Godot BoneMap).

### Проверка реализма (перед экспортом, `look` rendered + HDRI)

- Пропорции (рост ≈ 7–8 голов), постановка плеч и шеи, руки не «сосиски».
- Кожа: шероховатость не равномерная, SSS видно на ушах и носу против света.
- Глаза: блик, влажная линия, не смотрят в разные стороны.
- Волосы: нет жёсткого края на лбу, есть «пушок» по контуру.
- Одежда: складки в нужных местах (плечи, локти, колени), не прилипает.

## Персонажи из `generate_3d`

Далее обязательно: масштаб (рост в метрах) → Decimate/ретопология → UV → риг (Mixamo-авториг или Rigify) → проверка деформаций → материалы в стиле игры. Для крупного плана такие персонажи обычно хуже MPFB — честно скажи пользователю.

## Толпы

Один-два базовых тела MPFB + вариации (материал, одежда, волосы, морфы) → LOD (LOD2 ~1–2k tris) → в движке GPU instancing / импостеры для дальних.
