# Пример: городской дом XIX века, улица и люди (Blender MCP + MPFB2)

Проверочная сцена GameForge: реалистичное здание с модульными деталями, пропсы улицы и два человека MPFB2, HDRI-свет, рендер EEVEE. Каждый шаг — отдельный скрипт, очищает свою коллекцию и может перезапускаться с другими параметрами.

| Скрипт | Что делает |
|--------|-----------|
| `gf_lib.py` | хелперы: коллекции, box/prism/cylinder/room, Boolean-проёмы, фаски, PBR-материалы Poly Haven с процедурным фолбэком, вид вьюпорта |
| `10_townhouse_shell.py` | стены с проёмами и откосами, руст, цоколь, перекрытия |
| `20_townhouse_windows.py` | окна (рама, переплёт, стекло, комнаты, занавески), наличники, фронтоны, сандрики, витрины кафе, дверь, ступени |
| `30_townhouse_details.py` | пояса, карниз с сухариками и модульонами, руст углов, балкон с кованой решёткой, вывеска |
| `40_townhouse_roof.py` | черепичная кровля, щипцы, слуховые окна, дымоходы, жёлоб и водосток |
| `50_street_props.py` | брусчатка, тротуар, бордюр, фонарь, скамейка, столики, цветы, урна |
| `55_neighbours.py` | соседние дома (linked mesh, другой цвет штукатурки) |
| `60_light_render.py` | HDRI + солнце, камера пешехода, EEVEE |
| `70_human.py` | два человека MPFB2: тело, риг, кожа SSS, глаза, волосы, одежда, поза |
| `80_portrait_camera.py` / `85_restore_camera.py` | крупный план людей / возврат основной камеры |
| `run_all.py` | весь пайплайн по порядку |

**Нужно:** Blender 5.1+ с Blender MCP, MPFB2 + ассеты MakeHuman (`check-tools.py --task humans`), текстуры Poly Haven в `$GF_EXAMPLES_ROOT/textures/<asset>/` (без них — процедурные материалы).

**Запуск** (через `execute_blender_code`):
```python
import os; os.environ["GF_SCRIPTS"] = "<путь к этой папке>"
exec(open(os.path.join(os.environ["GF_SCRIPTS"], "run_all.py")).read(), {"__name__": "__gf__"})
```
Рендер — инструментом `render_viewport_to_path` (файл появится во временной папке из ответа).
